# 📊 Loan Default Data Power BI Dashboard

## 📌 Overview

This project presents an interactive **Power BI dashboard** built to analyze loan default data.  
The dashboard helps financial institutions and analysts:

- Understand loan repayment patterns  
- Identify high-risk customers  
- Track overall loan portfolio performance  

---

## 🛠️ Tech Stack

- **Power BI** – Data visualization and dashboard creation  
- **MS Excel / CSV** – Data source  
- **DAX (Data Analysis Expressions)** – Calculated measures & KPIs  
- **Power Query** – Data transformation & cleaning  

---

## 📂 Dataset

The dataset includes customer demographics and loan-related information.

### 🔑 Key Fields

- `Customer_ID` – Unique identifier for each borrower  
- `Age` – Borrower age  
- `Gender` – Borrower gender  
- `Income` – Annual income  
- `Employment_Type` – Salaried / Self-employed / Other  
- `Loan_Amount` – Total loan sanctioned  
- `Interest_Rate` – Applied interest rate  
- `EMI` – Monthly installment amount  
- `Tenure` – Loan duration  
- `Credit_Score` – Creditworthiness indicator  
- `Default_Flag` – Loan default status (Yes/No)  

---

### 📌 KPIs & Metrics
- Total Loans

#### 🌍 Geographical Insights
- Loan defaults by State/Region  

#### 💰 Financial Indicators
- Default rate by Loan Amount

#### 📊 Credit Score Impact
- Analysis of how credit score influences loan defaults  

### 🎛️ Filters & Slicers
- Year  
- Loan Type  
- State  
- Gender  
- Employment Type  

---

## 📈 Insights & Findings

- Customers with **low credit scores** had the highest default rate.  
- **Self-employed borrowers** showed higher default probability compared to salaried individuals.  
- Defaults were more common in **higher loan amount ranges**.  
- Younger age group (**25–35 years**) contributed significantly to defaults.  
- Certain regions demonstrated higher default risks, helping in targeted risk mitigation strategies.
